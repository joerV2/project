# Конспект → Карточки — учебный проект

Приложение для автоматического превращения учебных конспектов в карточки для запоминания (Anki, Quizlet, CSV/JSON). Работает с любыми форматами — от структурированного Markdown до фотографий рукописных конспектов.

## 🎯 Цель проекта

Ускорить подготовку к экзаменам: вместо ручного создания карточек — автоматическая генерация из конспекта. Приложение закрывает два сценария:

- **Базовый модуль** — для структурированных конспектов «вопрос — ответ» (Markdown, DOCX, TXT).
- **Модуль «Умные карточки»** — для неструктурированных и рукописных конспектов с использованием OCR и LLM.

## ✨ Ключевые возможности

**Базовый модуль**
- Импорт Markdown, DOCX, TXT
- Парсинг структуры «вопрос — ответ»
- Экспорт в CSV, JSON, Anki, Quizlet
- Предпросмотр и ручная правка карточек

**Модуль «Умные карточки»**
- OCR рукописных и печатных конспектов через камеру
- Разбиение неструктурированного текста на карточки с помощью LLM
- Гибкий выбор источника LLM: свой API-ключ (ChatGPT, Gemini), локальная модель (Ollama, LM Studio) или подписка на встроенную LLM
- Полностью офлайн-режим на базе локальных моделей

## 🛠 Технологии

- **Язык:** Python 3.10+
- **Интерфейс:** CustomTkinter / PyQt (десктоп), BeeWare / Kivy (мобильная версия)
- **Парсинг:** `markdown`, `python-docx`, `re`, `csv`, `json`
- **OCR (бесплатные локальные):**
  - **Tesseract** — лёгкий OCR для печатного текста
  - **EasyOCR / PaddleOCR** — нейросетевой OCR для сложных изображений
  - **Ollama + vision-модель** — для распознавания рукописного текста
- **LLM:** OpenAI API, Google Gemini, GigaChat, Ollama, LM Studio
- **Инфраструктура:** VDS для проксирования LLM и обработки подписок
